# Reproducible builds for the optional extras.
#
# Why a constraints file rather than a lockfile: the core has zero third-party
# dependencies (ADR-011), and everything below is optional. A full lockfile
# would pin transitive trees for extras most installs never enable, and would
# need regenerating per Python version and platform. Constraints pin the
# direct, security-relevant surface while leaving resolution to pip.
#
# Regenerate with:
#   pip install -e ".[all]" && pip freeze > constraints.lock.txt
# and commit the .lock.txt for a build you need bit-reproducible.
#
# Upper bounds are deliberate: an unbounded range means a future major
# release lands in production without anyone choosing it.
